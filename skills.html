DocuMind - AI Document Assistant

A full-stack Retrieval-Augmented Generation (RAG) application developed using Python, React, FastAPI and JavaScript. Allows users to upload PDF documents and ask questions using a locally hosted Qwen 2.5 AI model through Ollama. Features a responsive React interface, persistent vector storage, REST API integration and automated testing.
